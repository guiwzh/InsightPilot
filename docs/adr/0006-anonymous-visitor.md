# 0006 不做登录，用匿名访客

**背景**：这是一个给面试官体验的演示站点；要求对方注册登录会劝退大部分人。

**决定**：第一次访问时发一个 httpOnly 的 UUID cookie 作为访客 ID。会话按访客隔离，再加三道防刷闸：同一 IP 每分钟 10 次、每个访客每天 40 万 token、全站每天 ¥10。

**理由**：体验零门槛，同时 API 费用有上限（对应 OWASP LLM10 无界消耗）。

**代价 / 何时推翻**：换浏览器就看不到原来的会话；cookie 被清掉会被当成新访客（但 IP 限流和全站预算兜底）。要做多设备同步、团队空间、按用户计费时，再加正式的账号体系（如 Better Auth）。
