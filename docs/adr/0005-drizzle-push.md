# 0005 表结构用 drizzle-kit push 同步

**背景**：Drizzle 支持两种方式：写迁移文件（generate + migrate），或者直接把 schema 同步到数据库（push）。

**决定**：只用 push，不写迁移文件。用 `schemaFilter: ['app']` 让 push 只管 app schema，永远碰不到 shop 样例数据。

**理由**：个人项目、单人开发、只有一个线上库，迁移文件的版本管理带来的价值有限，却增加概念负担。

**代价 / 何时推翻**：push 会直接改表结构，删列、改类型可能丢数据（它会弹出确认）；多人协作、多环境、需要审计和回滚时，应该改用迁移文件。线上库的表结构目前是首次部署时从本机导出的。
